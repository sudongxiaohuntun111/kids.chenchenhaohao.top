# 精灵图资源目录

把 AI 生成的角色帧动画 PNG 放到这里，游戏会自动加载。

| 文件名 | 用途 | 规格 |
|---|---|---|
| `weilong.png` | 玩家角色：威龙 | 384×256 像素，4 行 × 6 列，每帧 64×64 |
| `warden.png` | Boss：典狱长 | 256×512 像素，4 行 × 2 列，每帧 128×128 |

> 若这两个文件不存在，游戏会使用内置的程序化像素角色，仍可正常游玩。

## 当前状态

- `weilong.png` 与 `warden.png` 已由用户提供的素材转制完成。
- 原图为 JPEG 黑底，已处理为透明背景 PNG。
- 游戏内对两张图做了 1.5 倍左右放大显示，保证手机和电脑上都足够清晰；后续替换新图时，可在 `index.html` 的绘制调用处调整 `96×96` / `176×176` 这些显示尺寸。

详细生成提示词见 `/workspace/SPRITE_PROMPTS.md`。

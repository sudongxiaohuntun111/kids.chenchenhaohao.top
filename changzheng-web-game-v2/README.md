# 《小红军长征记》2.0

## 本地运行
```bash
cd 长征网页游戏2.0
python3 -m http.server 8701
# 浏览器打开 http://localhost:8701/index.html#/intro
```

纯静态、无后端、可离线运行；首次打开建议从 `#/intro` 开始。

## 作品说明
作品面向 7—10 岁儿童，以真实标准地图 + 红飘带为主视图，采用「沿红飘带逐格前进」的旅程玩法：小红旗一次走一格、只向前不跳退，主站必经——必须完成该站的经典街机小游戏（华容道、青蛙过河、贪吃蛇、吃豆人、俄罗斯方块、打地鼠、记忆 Simon、别踩白块、一笔画等）才能点亮并走向下一站；站间穿插风景/历史/科学事件格。全部 10 个主站各有专属玩法，失败一律温和重试、不清空进度、不推倒重来。

状态只保存叙事印记与收集结果，不设置分数、生命、资源或百分比进度条。

## 地图合规
地图页使用自然资源部标准地图服务《中国地图》1∶740万界线版，原始文件位于 `assets/map/china_basemap_745.jpg`，审图号：**GS(2023)2767号**。来源、下载日期、SHA-256 和使用约束见 `docs/map-source-record.md`。红飘带、站点和路线是独立叠加层，不修改底图。

## 美术
核心融字图使用 youdiandou `gpt-image-2.5-sunburst` 生成，仅作叙事插画，不承载地理准确性。标准地图与 AI 插画严格分层。

## 目录
- `index.html`：入口与脚本加载
- `css/main.css`：剪纸/版画风样式和玩法样式
- `js/data.js`：站点、过场与文本数据
- `js/engine.js`：旅程印记、收集、补救、流程控制
- `js/games.js`：10站经典街机玩法注册与实现
- `assets/map/`：合规标准地图底图
- `assets/img/`：融字图与场景图
- `docs/map-source-record.md`：地图来源登记
- `docs/创作说明-A-B-C.md`：参赛说明材料
- `dist/changzheng-web-game-2.0-offline.zip`：离线交付包 + `SHA256SUMS.txt`

## 红线
文案和代码不使用数值进度/资源系统，不出现死亡、牺牲、伤亡、鲜血、惨烈等儿童界面表述；湘江只以“经历巨大困难但继续向前”低敏感交代。史实站点（乌江、遵义、腊子口、金沙江）按通行教材口径核正为常识性表述，不含可核验数字争议。

# 2026 创作者大赛说明会要点与本作状态

来源：仓库中的赛事原件 [`2026创作者大赛说明.pptx`](2026创作者大赛说明.pptx)。核对日期：2026-09-30。若组委会发布更新通知，以更新通知为准。

## 赛道要求

本作拟参加“数智交互 · 险阻解码 · 地理方向 · 历史回望”，不是“未来推演”方向。

说明会第 12 页的核心要求：以长征时空地图为基础，选取代表性自然险阻，通过地形、气候、水文、地貌风险等交互内容解释自然环境对行军的影响，并结合可靠史料呈现克服困难的过程；至少呈现两类科学信息。地图、路线和空间关系需要准确，网页需适配不同设备，并提交 README 与科学依据说明。

说明会第 15、17、19 页强调：使用自然资源部标准地图服务中的地图；地点、河流、山脉与路线须能和可靠地图相符；AI 生成地图不得冒充准确地图；需留存底图来源、年代和审图信息。

**要求边界：**说明会整理者曾提出“无国界顺序示意条”作为内部备选，但 PPT 原文没有说它可以替代时空地图。本作的顺序面板有助于理解章节顺序，不能据此宣称地图要求已完成。

## 交付材料与纪律

说明会第 18–19 页列出作品提交和配套材料要求，包括作品成品、运行说明、演示视频及创作说明等。演示视频不超过三分钟，并遵守 PPT 对录制和展示的要求；视频与盲评材料不得出现学生、学校、班级或指导教师身份信息。创作说明应按学校平台要求填写，披露 AI 使用范围和事实来源，并提供真实的提示词—生成结果—取舍记录。AI 生成内容不得作史料。具体提交字段和时间以学校通知及平台当期要求为准。

本作仍待：目标年龄试玩与迭代、合规地图与适用审核、干净离线包验收、三分钟演示视频、平台模板 PDF 定稿，以及负责人完成报名。最新状态见 [`提交检查清单.md`](提交检查清单.md)。

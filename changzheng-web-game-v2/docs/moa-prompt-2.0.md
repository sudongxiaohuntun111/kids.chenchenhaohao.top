# 三、已确认的核心机制（务必严格照此展开，不要改）
## 《长征红飘带 · 地图闯关式旅程》（无数值、无资源系统）
- **舞台**：一张准确的长征时空地图，一条「红飘带」贯穿站点（于都→乌江→遵义→四渡赤水→金沙江→泸定桥→夹金山→松潘草地→腊子口→会师）。
- **主循环（无任何数字条）**：走到一站 → 背景小故事(图推故事) → 抉择(该怎么过) → 险阻交互挑战(解释它) → 通关收集+点亮地图 → 下一站。
- **不用数值/资源系统**（明确弃用体力/补给/信念等一切点数）。
- **"选择产生实际影响"的替代设计**：抉择不扣数字，而是改变「这一站能否通过 + 下一站的叙事处境」。例：金沙江让伤员先上船→下一站开场伤员帮你指路(彩蛋)；抢着上船→下一站有战士掉队、叙事不同。选择改变旅程面貌与结局。
- **"长征的漫长与艰苦"的替代设计**：漫长=时空地图红飘带一站站推进（路程本身就是可见进度）；艰苦=每站用画面处境传递（夹金山走不动的战士变多、草地干粮袋看得见变少），不靠扣点。
- **状态延续**：上一站抉择/闯关结果带到下一站开场叙事，全旅程连续有因果，非孤立关卡。
- **收集成长线替代数值**：每站通关得风物拼图+知识卡+金句卡+站点勋章；会师时集齐拼成完整长征画卷；不同抉择收不同卡，鼓励重玩补全。
- **轻补救（老师④，不挫败）**：闯关卡住→老班长/队友轻提示(换一种过法/给线索)，随时可重试，不推倒重来；选择"难"不惩罚，用叙事温和呈现。

# 四、魂（北极星）
> 让长征真正走进孩子心里——历史科普与长征精神是灵魂，游戏只是表现形式。孩子玩完一章能复述一个历史知识点、记住一句金句、感受到那段艰苦而坚强的岁月。贯穿模型：游戏是腿(愿走)、叙事是眼睛(看见历史)、科普是心(记住精神)。

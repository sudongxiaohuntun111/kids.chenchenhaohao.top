《小红军长征记》2.0 创作说明

A. 创作理念

本作品面向7—10岁儿童，以“从烽火到星辰”为叙事主线。作品不把长征做成分数游戏，而是让孩子沿红飘带在真实时空地图上行走：先听故事，再做选择，随后通过自然险阻交互理解地形、水文、气候如何影响行军。

B. 交互设计

作品采用引章五幕、站点选择、险阻解码、科学解释、收集卡片和地图点亮的统一流程。十个主站分别对应浮桥、渡点、等高线、四渡迷阵、船队调度、铁索桥、雪山天气、草甸、侧崖迂回和三路会师等交互。每个玩法均支持温和提示和重试，不使用生命、资源、分数或百分比进度条。

上一站选择会成为下一站的开场叙事，过场懋功会师与吴起镇单独标识，避免与1936年三大主力会师混淆。

C. 地图、美术与技术

地图底图采用自然资源部标准地图服务《中国地图》1∶740万界线版，审图号 GS(2023)2767号，原图和来源记录保存在项目中。红飘带、站点和路线使用独立叠加层，不修改底图的国界、行政界线、图例和南海诸岛附图。

叙事融字图使用 youdiandou gpt-image-2.5-sunburst 生成，统一采用红、土黄、赭石、墨绿的剪纸版画风。AI插画只承担叙事与氛围表达，不承担地图准确性。

项目为纯静态 HTML/CSS/JavaScript，可离线运行，无后端依赖。旅程印记和收集状态只保存在浏览器 localStorage 中。

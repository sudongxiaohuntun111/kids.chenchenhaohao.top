# P2-action SPEC：10站实时动作玩法改造（方案二）

> 目标：把 10 站从"点对/按顺序点"的问答式交互，全部重写为**需要时机、反应、位置操作的实时动作小游戏**。保留历史与科学内容、收集/勋章/画卷、剪纸版画风格。
> 技术：每个玩法用一个 `<canvas>` 渲染（移动端触屏），共享一个 RAF 循环 + 点击坐标 helper。纯前端、无后端。中文 UI。
> 红线：**儿童向**——不出现死亡/流血/惨烈/伤亡字眼；失败一律"温和重试（再来一次）"，不惩罚、不死。每个玩法有清晰"开始"和"完成"态。

## 0. 全局：关卡门槛（本轮最关键）
- 修改站点流程：**必须先完成该站玩法，才点亮该站、才允许前进/返回地图后继续**。
- 「我通过了这一站」按钮：仅在玩法真正完成时可用；未完成时显示"先完成这一站的小挑战"且不可前进。
- 通关仍由玩法完成态触发点亮（引擎侧已有 stationCleared/印记，对接即可）。不得再"不玩直接跳过"。

## 1. 共享运行框架（games.js 顶部新增）
- `startGame(canvas, {w,h}, handlers)`：创建 RAF 循环、`dt`、点击坐标、`reset()`、`complete()`；`handlers: {update(dt), draw(ctx), onTap(x,y), onComplete}`。
- 统一：`h` 辅助已存在；canvas 宽度=容器宽，高约 320px；字体、按钮沿用现有样式；每次 `renderDanger` 独立实例，离开销毁循环。

## 2. 各站实时玩法规格（tap 触控为主）

### 站1 于都浮桥（时机·放置）
- 夜间河面。木板从左端桥手依次放下、匀速向对岸滑动。
- 玩家在木板经过缓流锚点时点击锚点放置；提前/错过 → 木板漂回，温和提示"木板没接住，再来一次这块"。
- 敌机周期性掠过；若放置时敌机正上方 → 木板"先藏起来"，重放该块（教昼/夜藏桥）。
- 5 块放完 → 完成态"桥搭好了"。

### 站2 乌江渡江（时机·停靠）
- 竹筏在河上从左向右、速度忽快忽缓移动。
- 在"陡崖下旋涡"停靠区高亮时点击 → 竹筏靠岸；提前/过晚 → 竹筏被冲回，重试。
- 停靠成功 → 绑竹筏/试水/调整靠岸点三格点亮 → 完成态"渡点选好"。

### 站3 遵义通道（路线·反应）
- 等高线地形格，红点从南向北移动；玩家点击左/右/直切换行进方向，避开"密线高山"格。
- 撞到密线格 → 温和提示"山太陡，拐个弯"，红点回退一格重试。
- 抵达山口/河谷出口 → 完成态"出口找到"。

### 站4 赤水迷阵（躲避·时机）
- 小红军标记需依次渡过 4 段河湾。灰色敌军影子按固定路线巡逻。
- 玩家在影子远离河湾时点击"趁空渡过"按钮 → 标记前进一段；影子贴近时点 → 提示"被发现了，躲进山影等下一轮"，可重试。
- 4 段渡完 → 完成态"调虎离山成功"。

### 站5 金沙江渡江（时机·顺序）
- 4 类队伍（侦察/伤员/装备/大队）依次沿江漂来。
- 玩家须在正确顺序的那只船到达停靠点时点击；点错/错过 → 温和提示"顺序要按探路→伤员→装备→大队"，重来。
- 4 只按序上船 → 完成态"渡江守则达成"。

### 站6 泸定桥铺桥（时机·抓取）
- 木板从两岸向中间滑动；玩家在木板经过本侧接板点时点击接住。
- 阵风会把已放木板吹偏一块 → 温和提示"风把木板吹偏了，重新稳住"，重放该块。
- 5 块铺完 → 完成态"峡谷铺桥完成"。

### 站7 夹金山（时机·选时+挖孔）
- 环节一：天气窗横条移动，玩家在"正午晴朗"窗口内点击出发；选到晨/昏 → 风雪动画+温和提示，重选。
- 环节二：5 个踏雪孔沿坡依次点亮又变暗，玩家在点亮时点击开挖；错过 → 该孔重亮重试。
- 5 孔挖完 + 结伴标记放队伍中间 → 完成态"踏雪开道完成"。

### 站8 草地（反应·踏草甸）
- 迷雾从左向右逼近；草甸格会随机发光。玩家须在迷雾到达前点击安全草甸格前进，踩到泥潭格 → 温和提示"泥潭下陷，大家拉住你，换一块"重试该步。
- 走通草地 + 背靠背取暖/互相递水两格点亮 → 完成态"看清草甸再下脚"。

### 站9 腊子口（时机·序列）
- 侧崖攀爬者向上移动；玩家在信号窗口打开时依次点击"正面牵制→侧崖攀爬→发信号"。
- 顺序错或错过窗口 → 温和提示"信号没接上，再试一轮"，重试。
- 序列完成 → 完成态"侧崖打开通道"。

### 站10 会师（反应·汇合）
- 三条红箭头各自绕过障碍（山脉/河湾）向会宁/将台堡汇聚；玩家在箭头接近障碍时点击变向避开。
- 撞到障碍 → 该箭头回退温和提示"换一条沿河谷的路"，重试。
- 三路汇聚 → 点击点燃会师火炬 → 完成态"三路星火终于相聚"。

## 3. 工程与验收
- `games.js` 中为每站重写实时玩法函数并保持注册名（bridge/ferry/channel/maze/boarding/plankBridge/snowPass/marsh/cliffRoute/rendezvous）。
- 不重写 data.js 文案结构；每站仍调用科学解释、保持收集。
- 每站验收（浏览器实测）：
  1. 直达路由渲染 canvas，非占位
  2. 玩法可真实开始、有反应/时机元素
  3. 失败路径温和提示且可重试
  4. 正确路径出现完成态
  5. **未完成时「我通过了这一站」不可前进**
  6. node --check js/*.js 通过；离开站点不残留 RAF 循环
- 逐站分批实施并独立验证，不采信执行端自报。

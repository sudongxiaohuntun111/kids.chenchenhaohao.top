# 长征2.0 P0b1 SPEC：核心引擎框架

> 执行端：Codex CLI（goaichat profile）。Hermes 只做指挥与验证。
> 前置：P0a 已完成（index.html / css/main.css / js/main.js / js/data.js 已存在且可用）。**在现有文件上扩展，不要重写结构。**
> 设计依据：`docs/顶层设计-2.0.md` 第 6 章（易上手体系）+ 第 7 章（无数值选择/状态/收集/补救）。

## 1. 任务目标
在 P0a 骨架上实现**核心引擎系统**（全站通用，不绑定单站玩法）：
- 旅程印记系统（选择保存 + 下站开场叙事联动）
- 收集系统（无进度条，空槽表示未收集）
- 轻补救系统（老班长提示 / 换一种过法 / 重试，不做数字计数）
- 红飘带地图交互（点击进站、通关点亮、红飘带推进）
- 通用站点流程控制器（🔴故事→🟡抉择→🟢险阻→🔵科普→收集→点亮地图）

## 2. 现有结构（不要破坏）
- `js/data.js`：`STATIONS`(10站, 含 `choice[]`, `interactive{type:"TODO"}`), `INTRO_QUOTES`, `TRANSITIONS`。
- `js/main.js`：hash 路由 + 引章五幕 + 站点页渲染（P0a 已实现站点页展示故事/抉择/科普/金句/勋章）。
- `css/main.css`：剪纸/版画风，四色胶囊类已存在。

## 3. 引擎设计（新增 `js/engine.js`，在 index.html 中于 main.js 之后引入）

### 3.1 旅程印记系统（localStorage key `cz_journey`）
- 格式：`{ [stationId]: choiceIndex }`，每站只存 0/1/2（选过的抉择下标），不存数字/分数。
- 站点页 🟡 抉择：点击选项后保存印记、高亮已选项，并允许在本站内改选（改选会更新印记）。
- 下站开场叙事联动：站点页 `#/station/<id>` 渲染时，读取上一站印记，把该站 `story` 前插入上站影响叙述（格式见 3.5）。上一站无印记则不插入。
- localStorage 读写封装成 `journeyGet()/journeySet(id, idx)`。

### 3.2 收集系统（localStorage key `cz_collect`，无进度条）
- 每站通关后解锁 4 件套：风物拼图 + 知识卡 + 金句卡 + 勋章，存为 `{ [stationId]: true }`。
- **绝不显示数字进度**；地图/收集页用**空槽位**表示未收集，已收集显示卡面/勋章。
- 站点页 🔵 历史科普后显示「通关收集」区：4 件套以卡槽形式呈现，已通关即点亮。
- 提供 `collectGet()/collectUnlock(stationId)`。

### 3.3 轻补救系统（不挫败，无数值）
- 站点页 🟢 险阻交互区固定右下角两个按钮：
  - 「老班长提示」：第一次给一条行动线索（非直接答案）；再点第二次显示历史解法并缀一句「当年红军就是这样做的」。
  - 「换一种过法」：重置当前站的险阻交互为初始状态（可重试），**不清空旅程印记**。
- 全程**不出现「你还剩 X 次」等数字**。

### 3.4 红飘带地图交互（改 `#/map` 页）
- P0a 地图页已是 10 站列表。改为：每站一个「站点卡」，点击进入 `#/station/<id>`。
- 已通关站点：站点卡点亮 + 红飘带延伸（用 CSS/SVG 画一条从于都到该站的红色连线，可简化为「已通关高亮 + 下一站是当前目标」）。
- 地图页顶部显示「当前站点 / 下一站」，**不显示百分比/数字进度**。
- 过场（懋功/吴起镇）在地图页以小星点标注，点击可看过渡文案（`TRANSITIONS`），不计通关。

### 3.5 通用站点流程控制器
`#/station/<id>` 渲染流程（在 P0a 站点页基础上补齐按钮与状态）：
1. 🔴 背景故事（已有）
2. 🟡 该怎么走：点选项→`journeySet` 保存印记，显示已选。
3. 🟢 险阻解码：P0b1 阶段若 `interactive.type==="TODO"`，显示占位卡 + 「老班长提示 / 换一种过法」按钮框架（玩法本体 P0b2 填）。**若站点无玩法则跳过。**
4. 🔵 历史科普 + 通关：设「我通过了这一站」确认按钮→`collectUnlock` + 勋章点亮 + 返回地图（红飘带推进）。过场站不设通关按钮。
- 站点页顶部显示「第 N 站 / 10」。

## 4. 红线（延续 P0a，全站适用）
- 不出现任何进度条/体力条/资源条/点数/百分比数字；卡槽用空位表示未收集。
- 不出现死亡/伤亡/惨烈表述；不涉及国家领导人；人物用泛称。
- 抉择只存印记（0/1/2），不产生失败/重开/扣分。
- 通关按钮文案不用「答对」「考试」，用「我通过了这一站」。
- 全部中文；按钮≥48px；字体≥20px；无动画超4秒。

## 5. 验收标准（Hermes 独立验证）
1. `js/engine.js` 存在且 `node --check` 通过；index.html 正确引入（data.js→main.js→engine.js 顺序）。
2. localStorage 读写：在 `#/station/yudu` 选一个抉择→刷新→仍选中；`cz_journey` 含 `yudu:idx`。
3. 下站叙事联动：选于都「拆桥隐蔽」→进 `#/station/wujiang` 开场出现「工兵和船工完整跟上来」类影响句。
4. 通关收集：点「我通过了这一站」→地图页该站点亮、收集卡槽点亮、无数字。
5. 轻补救：「老班长提示」「换一种过法」按钮存在且可点击，不出现数字计数。
6. 红线：无进度条/资源/点数；无死亡伤亡词；通关文案正确。
7. 引章五幕仍可用（不回归）。

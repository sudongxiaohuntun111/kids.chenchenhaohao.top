## 3. 引章五幕（蓝图 §5，务必实现，防秒跳）
五幕，每幕一屏，**必须有手部操作**，末幕完成「地图碎片归位」后出现「开始长征」按钮。
- **不设「全部跳过」**，只设「我已明白」逐幕确认；单幕可快进，整段不可跳过。
- 第一幕·烽火启程：一句话背景「1934年10月，一支队伍从于都出发。路上遇到了出发以来最艰难的一战，队伍经历了巨大困难，但依然继续向前。」配插画占位。
- 第二幕·地图展开：红飘带连接10站，教认「于都→会师」路线。
- 第三幕·险阻四色：介绍 🔴历史故事 🟡该怎么走 🟢险阻解码 🔵历史科普 四色胶囊。
- 第四幕·行走与选择：说明「无数值」——没有体力条资源条，选择改变下一段旅程。
- 第五幕·你的长征：说明收集（风物拼图/知识卡/金句卡/站点勋章），末幕地图碎片归位 → 「开始长征」。
- 文案硬约束：气泡≤2行、正文≤90字/屏、按钮≥48px、字体≥20px。

## 5. 站点数据 `js/data.js`
定义 `STATIONS` 数组，10 站各一个对象，字段（从顶层设计-2.0.md 第3章逐站提取）：
```
{
  id: "yudu",
  name: "于都出发", time: "1934.10", sciTag: "水文+地貌",
  quote: "东方欲晓，莫道君行早。",      // 金句
  badge: "渡河先锋",                   // 站点勋章
  story: "...",                        // 背景小故事方向（≤90字，蓝图3.x「背景小故事方向」）
  choice: [ {text:"...", effect:"..."}, x3 ],   // 抉择3选项 + 对下一站的影响（蓝图「抉择」）
  sciExplanation: "...",               // 险阻交互的科学解释一句话
  trivia: "...",                       // 历史小科普（≤70字，蓝图「历史小科普」）
  interactive: {type:"TODO", desc:"..."}, // 险阻交互玩法占位（本阶段仅描述，P0b实现）
  understanding: "..."                 // 孩子获得的理解（蓝图「解释链」最后列）
}
```
另含 `INTRO_QUOTES`（七首诗词，可沿用）与 `TRANSITIONS`（懋功/吴起镇过场文案）。
**所有文字必须与顶层设计-2.0.md 一致，不得自行改写史实数字。**

## 6. 技术约束（红线）
- 纯静态：无后端、无外部依赖、可 `file://` 或 `http.server` 离线运行；不收集个人信息；无外部 API。
- 中文 UI；正文字体≥20px；按钮点击区≥48px；无动画等待超4秒。
- 不出现任何「体力条/资源条/进度条/点数」。
- 不出现死亡/伤亡/惨烈表述；不涉及国家领导人；人物只用「老班长/战士/船工/向导」等泛称。
- 页面底部固定位置保留「审图号」占位文本（后续地图阶段填入真实审图号）。

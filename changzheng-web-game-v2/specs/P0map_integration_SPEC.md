# P0-map SPEC：标准底图接入游戏地图页

## 来源
使用 `assets/map/china_basemap_745.jpg`，来源登记见 `docs/map-source-record.md`。
审图号必须显著保留：`审图号：GS(2023)2767号`。

## 实现
- 由 Codex 修改 `js/main.js`/`css/main.css`，不改原始 JPG。
- `#/map` 页面增加固定底图层：使用该 JPG，`object-fit:contain` 或等比例背景，确保不裁掉南海诸岛附图与审图号。
- 红飘带和站点标记必须是独立 SVG/DOM 叠加层，不能把路线绘制进 JPG。
- 站点地图先保证“可读、可点、可验证”；路线标记不得覆盖原图审图号、图例、南海附图。
- 保留现有地图卡片/路由/已走通状态；底图加载失败时显示明确的本地资源提示，不黑屏。
- 页面文字注明：`底图来源：自然资源部标准地图服务｜审图号：GS(2023)2767号`。

## 验收
1. `#/map` 初次加载可见全国底图、红飘带、10站卡片。
2. 审图号文本可从 DOM 读取，且底图原图文件实际被引用。
3. 点击站点仍能进入站点；引章和既有玩法不回归。
4. 原图 SHA-256 与 map-source-record 一致；不改 JPG。
5. 浏览器控制台无错误，node --check 通过。

## 3. 于都站玩法「昼拆夜搭浮桥」（蓝图 §3.2，务必照此实现）

### 玩法设定（面向 7-10 岁，简单、不挫败）
- 画面分「昼 / 夜」两种状态，可切换（按钮「到夜里」「到白天」）。
- 河面有 **5 段浮桥**（木板节，标 1-5）。岸上有 **5 个锚点**（放桥的缓流位置点）。
- **玩法目标**：先在夜里把 5 段浮桥按正确水流方向依次放到河面锚点上；到白天时，敌机影子会飞过，必须先把已搭的桥「分散藏到岸边」（点藏桥），否则被敌机发现 → 温和提示（不惩罚失败，只是提示）。
- **科学动作**：孩子发现「河湾处（弯道内侧）水流缓，这里好搭桥；直河段水流急，桥会被冲歪」——桥放在缓流锚点才能固定，放错则显示「被水冲歪」动画、可重排。
- **完成判定**：夜间 5 段浮桥全部稳稳搭在缓流锚点上且连接顺序正确（1→2→3→4→5 顺水势由上游向下游）→ 显示「浮桥搭好了！」，点亮通关（触发 main.js 的「我通过了这一站」仍由玩家点击）。

### 交互实现要求
- 纯 DOM（div/button/drag），**不引入 canvas**；支持鼠标拖拽与移动端 touch。
- 操作不复杂：点击桥节→点击锚点放置（比拖拽对儿童更稳），或 HTML5 draggable。二选一，有明显视觉反馈。
- 错误不惩罚：放错锚点 → 「水冲歪」动画 + 文字「这段水流太急，桥站不住，换个缓流位置」，桥节弹回岸上可重试。
- 昼/夜切换有简单视觉变化（天空色/月亮太阳）。
- 敌机影子：昼间随机飞过，提示「把桥藏到岸边」；点了藏桥则安全，不点则温和提示（不出失败画面）。
- 顶部小贴士：「先看河弯，缓流处才好搭桥」。
- 轻补救沿用引擎：卡住时「老班长提示」给线索。

### 站2 乌江 `type:"ferry"` — 找一处可渡点
**玩法**：
1. 渲染一张乌江局部示意（三段渡口横向分布）三个可选点：
   - **窄谷急流**（水流最急）— 图卡：水势★急 / 岸形★窄 / 隐蔽★★
   - **宽滩缓流**（水缓但开阔）— 图卡：水势★缓 / 岸形★宽 / 隐蔽★（易暴露）
   - **陡崖下旋涡**（有旋涡）— 图卡：水势★★ / 岸形★★ / 隐蔽★★★（视线被崖挡）
2. 点击任一点弹出三要素图卡（水势/岸形/隐蔽）。
3. 儿童按「水势要缓、岸形可停靠、又有隐蔽」选出合理渡点。正确答案是**陡崖下旋涡**（水势次缓、可停靠、最隐蔽）。
4. 选错（窄谷急流/宽滩缓流）→ 温和文字「这里水流太急 / 太开阔容易被发现，再看一眼水势、岸形、隐蔽三条线索」，被选项打×，可重选。
5. 选对 → 进入短交互：三动作「绑竹筏 → 试水 → 调整靠岸点」依次点亮，每步一句文字说明，最后显示「渡点选好，竹筏下水稳！」通关态。
**完成态**：出现可通关按钮仍由主引擎「我通过了这一站」触发。

### 站3 遵义 `type:"channel"` — 等高线上找出口
**玩法**：
1. 渲染遵义以北地形示意：用**等高线密度**表示山地（密线区标「山」），三条虚线候选北上通道。每条通道标注经过的「山口 / 河谷 / 山脊」类型。
2. 儿童点选一条通道。系统反馈：
   - 选**河谷或山口**通道 → 绿色「可通行，靠山谷省力」。
   - 选**穿越山脊/等高线最密**通道 → 温和提示「这里等高线太密、山太陡，换一条沿山谷的」。
3. 三条候选里仅一两条正确（沿河谷/山口的）。正确通道弹出「密线是高山，山口是通道」小卡。
4. 完成即弹出「出口找到——赤水方向的河谷」。通关态出主按钮。
**科学呈现**：底部固定文案直接引用 data.js 的 sciExplanation「等高线密处难走，山口与河谷是天然通道」。

### 站4 赤水 `type:"maze"` — 四渡迷阵推演
**玩法**：
1. 渲染赤水河曲底图示意（河曲+山体色块遮蔽），右侧四步序号Ⅰ/Ⅱ/Ⅲ/Ⅳ。每步给 2 个方向候选（如「向东南渡」「向西北撤」）。
2. 儿童依次选 4 次渡河方向。每次选择后，一个**敌军灰色影子**在图上跟着移动或被引开；「我军红点」沿河曲机动。
3. 目标：4 步内把敌军影子**引到远离渡口的方向**。若某步让红点与灰影撞上，温和提示「被追近了，换个方向」，该步可重选。
4. 4 步全选对（把敌人调开）→ 回放：显示 4 次「来回机动」的红点轨迹与「距离变化说明」（文字：先向西引、再向东穿、绕回河边……），最后「调虎离山成功，渡口空出来」。通关态出主按钮。
5. 简单化：4 步候选中只有唯一正确序列，渐进验证（选错可回退上一步重试）。

### 站5 金沙江 `type:"boarding"` — 渡江秩序调度
**玩法**：
1. 渲染 7 只小船模型横排，江流从左向右箭头。右侧四类待上船：**(1)伤员 (2)装备 (3)侦察分队 (4)大部队**，各有文字说明「先过江能先探路/守住渡口」。
2. 儿童按顺序拖/点选把四类放入前 4 只船（后 3 只空船稍后示意返航）。
3. 正确顺序（参考历史守则，简单化）：**先侦察分队（过江先探路守口）→ 伤员（先过去安置）→ 装备（物资跟上）→ 大部队（最后大队有序）**。
   - 若把大部队放太前 → 动画「船队拥挤、江浪把船冲偏」，温和提示「江急船少，先让最前面需探路的部队和伤员先过」。
4. 放对 → 每放一只点亮一只船「按序上船」，四只点完显示「渡江守则：探路→伤员→装备→大队」。通关态出主按钮。
**科学呈现**：底部固定文案引用 data.js sciExplanation「江面窄但水流急，多船并排不易，必须有秩序」。
